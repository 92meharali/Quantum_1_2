# Intro to Quantum Computing & Qiskit (Part 1 & 2)

## Overview
This repository serves as an introduction to Quantum Computing using IBM's **Qiskit** framework. It covers the foundational concepts of quantum states, operators, and various state visualization techniques essential for quantum algorithm development.

## Features
- **Quantum Circuits:** Basics of constructing and simulating quantum circuits.
- **State Visualization:** Deep dive into visualizing quantum states using `plot_state_city`, `plot_bloch_multivector`, `plot_state_qsphere`, and `plot_state_paulivec`.
- **Simulation:** Utilizing Qiskit Aer simulators to run statevectors and obtain histograms of measurement outcomes.

## Technologies Used
- Qiskit (Quantum Circuit Creation & Simulation)
- Qiskit Aer (Local Simulation)
- Matplotlib (Visualization Support)

## How to Use
1. Clone the repository.
2. Install the required dependencies: `pip install qiskit qiskit-aer matplotlib`.
3. Open `Quantum_1_2.ipynb` to explore the quantum circuits and visualizations.
